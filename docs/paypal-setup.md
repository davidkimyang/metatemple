# metatemple 공양미 후원 준비

현재 공개 화면은 **결제 준비 중**입니다. 금액 선택으로 결제되지 않으며 PayPal 스크립트나 결제 API를 호출하지 않습니다. 기존 사이트 공개 범위도 변경하지 않았습니다.

## 준비 완료

- 밥그릇 버튼 → 18개 언어의 공양미 안내창.
- 가상 공양미 / metatemple 서버와 콘텐츠 운영 지원 / 자율 후원 / 무료 입장 안내.
- 동일한 크기의 $1, $5, $10 USD 일회성 선택. 기본 선택 없음.
- 서버가 상품 ID로 고정 가격을 결정하는 카탈로그: `lib/offerings.ts`.
- 계정 연결 후 사용할 **샌드박스 전용** 서버 어댑터: `lib/server/paypal.ts`.
  OAuth, 주문 생성, 승인된 주문 캡처, 요청 ID, 최종 캡처 금액·통화·상태 검증 포함.
- 모의 응답 테스트: `node tests/offerings.mjs`.

어댑터는 실제 HTTP 결제 경로에 연결되지 않았습니다. 환경변수나 키를 넣는 것만으로 결제가 열리지 않습니다. 현재 성공/취소 화면이나 감사 애니메이션도 고객에게 가짜로 표시하지 않습니다.

## 계정 준비 후 이어서 할 작업

1. PayPal 비즈니스 계정의 수취 가능 상태 확인. 계정 심사·지원 여부는 PayPal에서 결정합니다.
2. Developer Dashboard에서 샌드박스 판매자/구매자 계정 및 앱 발급. 실제 정보는 저장소·채팅 대신 Sites의 서버 런타임 비밀 설정에 보관합니다. 필요한 키 이름은 `.env.example` 참고.
3. D1에 후원 원장 추가: 불변 상품 ID·가격·통화, 방문자 소유권, 생성/캡처 요청 UUID, PayPal 주문/캡처 ID(고유 제약), 상태·시간만 저장. 카드 정보는 저장하지 않습니다. 방문자 접속 행은 18초 후 만료되므로 결제 원장과 분리합니다.
4. 동일 출처 검증·요청 크기 제한·속도 제한·소유권 검증이 있는 주문 생성/캡처 API 연결. 클라이언트는 상품 ID만 전송합니다. 서버가 원장에 요청 UUID를 먼저 저장하고 재시도에도 같은 UUID를 사용합니다. 승인 이벤트나 URL 쿼리만으로 성공 처리하지 않습니다.
5. PayPal SDK 버튼을 금액 선택 후에만 연결. 캡처된 금액·통화·상태 및 수취 판매자 확인 후 원장 상태를 원자적으로 갱신합니다. 성공 때만 감사 표시. 취소는 중립 안내, 결제 거절/네트워크 오류는 중복 결제 없는 재확인 동선으로 처리합니다.
6. 서명 검증 및 중복 이벤트 방지가 있는 웹훅, 캡처 재조회·대사 처리 추가. 현재 사이트는 소유자 전용이므로 PayPal이 도달 가능한 HTTPS 콜백 경로를 별도로 결정해야 합니다. 이를 위해 사이트 공개 범위를 임의로 바꾸지 않습니다.
7. 샌드박스에서 세 금액, 성공, 취소, 거절, 보류, 네트워크 끊김/응답 유실, 반복 클릭, 재시도, 다른 방문자의 주문 접근, 변조 금액, 웹훅 재전송을 검증합니다.
8. 실제 운영자/문의처 및 후원·환불 안내를 확정하고 배치. 실제 공양미 전달이나 기부금 영수증 발급을 약속하지 않습니다.
9. 라이브용 키와 서버 설정을 분리해 연결. 현재 샌드박스 전용 어댑터를 명시적으로 확장하고 검토한 후 활성화합니다. metatemple.net 도메인 연결 상태도 확인합니다. 현재 배포 주소는 chatgpt.site입니다.

실제 PayPal 결제·취소·환불·웹훅 검증은 계정 연결 전에는 완료할 수 없습니다. 현재 테스트는 모의 응답을 사용합니다.
